## 7. Suggested plan for 01–04

Each page wants one topic and 1–2 short quotations.

**01 Health as Language** — the campaign was delivered through the health system, and the justification kept changing while the demand stayed the same. The four posters run 1972 → 1974 → 1986 → 1987: revolution, then medicine at the door, then law, then eugenics.
Quotes: the "barefoot doctors" line; optionally the "gene pool" line.

**02 Two Chinas** — one national policy, three different realities: urban (dense oversight, high compliance), rural (1.5-child rule, thin monitoring, children as economic security), exempted minorities.
Quotes: "urban bias"; the peasants/fines line. Needs no image, though you could move a poster here.

**03 Missing Daughters** — the sex ratio as evidence that enforcement varied by place. The looser 1.5-child rule produced the *worse* imbalance, because a couple whose first child was a girl got exactly one more chance.
Quotes: the 111.6 vs 124.7 line; the Fujian/Anhui line. Map and chart already on the page.

**04 The Backfire** — the reversal. Fertility was already falling before 1979 and kept falling after 2016, so lifting the limit changed little; the obstacle is now cost, not permission.
Quote: Wang Feng. Graph already on the page.

A possible through-line for the whole site: the number the government wanted changed, but the premise that the government sets the number did not.

## 8. Editing and publishing the site

The site is a single self-contained HTML file. Do not edit it directly — edit the source and rebundle.

```
src/template.html     <- the page you edit
tools/rebundle.js     <- folds template.html back into the standalone file
tools/unbundle.js     <- extracts template + assets back out
tools/addasset.js     <- adds a new image to the bundle
```

**To change text:**
1. Edit `src/template.html`. Pages live in `<sc-if value="{{ isS1 }}">` … `</sc-if>` blocks (`isS1`–`isS4` are pages 01–04).
2. Run `node tools/rebundle.js`
3. `git add -A && git commit -m "..." && git push`
4. GitHub Pages rebuilds in about a minute.

**To add an image:**
```
node tools/addasset.js <some-uuid> path/to/image.jpg
```
Then reference it as `<img src="<some-uuid>">` in the template. The seven already embedded are `a1000000-0000-4000-8000-00000000000{1..7}`:
